# Course design

## Objective

The learner should build fast lexical access for English Tafsir competition, not merely recognize translations in a list.

## Lesson size

Each page is split into micro-lessons of up to 6 `CORE` lexemes. `SUPPORT` words remain available in Qur'anic context but are not prioritized as standalone drills.

## Exercise progression

1. **Learn** — Arabic + English + optional Indonesian helper.
2. **Matching** — rapid Arabic/English association.
3. **Arabic → English** — recognition.
4. **English → Arabic** — reverse discrimination.
5. **Context** — retrieve meaning while seeing the ayah.
6. **Typing recall** — productive retrieval without choices.
7. **SRS review** — delayed retrieval.
8. **Tafsir practice** — explain the word and its function in the ayah in English.

## Why Indonesian is secondary

The target performance language is English. Showing Indonesian can remove ambiguity during early learning, but making it the mandatory intermediate representation would slow direct English retrieval.

## Valid-answer policy

A lexeme may have multiple accepted English meanings. The course stores `englishPrimary` plus `englishAlternatives`. Human curation should add legitimate alternatives rather than marking them as wrong.

## Mastery

- `NEW`
- `LEARNING`
- `FAMILIAR`
- `STRONG`
- `MASTERED`

Mastery is based on repeated successful retrieval and delayed review, not a single correct multiple-choice answer.

## Review behavior

- failed retrieval: approximately 10 minutes
- first successful interval: 1 day
- next successful interval: 3 days
- later successful intervals expand using the ease factor

## Page completion

A page is unlocked sequentially. Passing the final micro-lesson marks the page complete; mastery stars reflect lesson performance and can improve with later sessions.
